# ADR 0003: Explicit optional inference connections

Status: accepted for version 0.3.0. Date: 2026-09-05.

The author requested OpenAI, Anthropic, OpenRouter, Venice, LM Studio, Ollama, and custom endpoints alongside browser-local inference. Preserve the existing world/execution/coordination graphs, persistence, context compiler, and deterministic canon authority. Introduce a small transport adapter at the existing completion port; do not add an inference backend, remote checkpoint store, SDK dependency, or remote embeddings.

Local inference remains the initial setting. A connection becomes active only after its destination disclosure is accepted in Settings. Configuration drafts do not make requests; explicit model-list lookup is a credentialed metadata GET. Generation/extraction/author assistance use the selected connection, with a visible API badge and operation-specific disclosure. Local model failure cannot select a remote connection.

Provider configuration and keys are browser settings, outside the portable Project schema and database. Session keys are the default; persistent unencrypted storage is opt-in. Native imports cannot choose endpoints or supply credentials. Fixed cloud presets cannot be redirected to other hosts; custom/local profiles require explicit URL entry and key reentry after URL changes. Requests omit cookies/referrers, reject redirects, use only application-owned paths, have a two-minute deadline, and never retry automatically. Model-list queries have a twenty-second deadline. Responses are bounded and provider error bodies are not surfaced. A verbatim credential echo is redacted as a narrow exception to preserving external output.

Each workflow run captures the selected connection before asynchronous work. The completion port refuses to send if it changes before the request; a changed selection while a request is running preserves its result but routes the workflow to synchronization. Explicitly resuming a saved workflow uses the currently selected connection and records its model label and destination origin before invocation. No imported model label controls routing. The graph still returns text/proposals only, with deterministic schema/reference/consistency checks and human approval before canonical commits.

The page CSP must permit arbitrary HTTPS connections and loopback HTTP to support user-supplied endpoints. Script/worker/image/font restrictions remain; the browser-local model workers retain their own strict asset-only network gate. This necessarily broadens the page's connection envelope. The application transport's explicit destination and action checks enforce ordinary request behavior; CSP is not claimed to constrain a compromised same-origin script to a dynamically selected provider. There is no Storied CORS bypass or proxy. The original default-local network regression tests remain applicable to default mode.

API contracts, operational instructions, key risks, unsupported features, and verification limits are in [PROVIDERS.md](../PROVIDERS.md). Protocol fixtures cannot prove provider account access or prose quality. MCW-inspired runtime repair remains application engineering, not a validated scientific coordination measurement.
